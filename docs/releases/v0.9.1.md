# V9.1 / 0.9.1 · 视角首次提示（V9 小增补）

日期：2026-11-07。状态：本轮改动并入 V9 发布线，作为 **补丁版本 0.9.1** 推送并重新部署现有魔搭 Docker。`v0.9.0` 已先一步完成推送、tag 与部署，tag 不移动；本次只增加引导与一句说明，不改玩法与资产。

## 这一版变了什么

- **首次点击右下角眼睛**：在视角控件上方弹出一次气泡，说明「眼睛亮起＝固定视角、视角可以选中」，并提示**滚动滚轮快速切换** 正面 → 斜 45° → 侧面 → 俯视。点「知道了」或约 6.5 秒后自动收起。
- **首次拖动画面**：拖动会自动切到自由视角，以前只有图标悄悄熄灭；现在同一位置给一次说明「已切到自由视角」，并告诉用户点眼睛回到固定视角、滚轮快速切换。拍照阶段（自由构图）不弹这条。
- **只提示一次**：两类提示分别用 `bouquet-workbench.first-use.*` 记在本机 localStorage，刷新、重开、下次发布都不重复；不写作品 JSON、不进撤销栈、不影响导出。
- **包装阶段发现性补一句**：左栏说明增加「也可以直接点画面里的纸片、花器或贺卡来编辑」，让 V0.7 §6 的 3D 直达编辑更容易被发现。
- **同类控件审计**：辅助 / 相册 / 更多 / 阶段节点 / 花材架 / 就近工具条已有文字标签或常驻说明（如「点花材取花」「拖动空白处转视角」「快捷键」），本轮不再叠加提示，避免打扰。

## 为什么是 0.9.1 而不是改写 V9

用户要求把这处小改动并入 V9。执行时 `v0.9.0` 已由并行会话完成推送、`v0.9.0` tag 与魔搭部署，按 推送与版本约定“已发布 tag 不重写、修补用补丁版本”，本次记为 **0.9.1** 并在发布说明写明原因；功能和资产仍属于 V9 这条线。

## 保留的边界

- 提示只做一次性引导，不改变固定 / 自由视角的实际逻辑；滚轮阈值（累计 90、320 ms 节流）未改。
- 提示是否「好看、位置是否挡画面」需要用户实际看一眼；如嫌打扰，可改为只保留眼睛的 title，不弹气泡。
- 类似控件只做了审计与一句常驻说明，没有给每个按钮都加首次提示。
