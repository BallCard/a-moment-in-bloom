# V16 / 0.16.0 · 花材与制作流程升级

更新：2026-11-10。版本：**0.16.0**。本轮把用户试玩反馈整理出的升级计划（`docs/flower-workflow-upgrade-plan.md`）两轮全部落地，并按用户追加要求用 API 生成背景音乐、用 Lux3D 补齐两种主花真实模型。

## 用户能体验到的变化

**花材与挑选**
- 花材架新增 12 个商品类目，按「主花 / 配花 / 叶材」三组做紧凑入口（点组才展开小类），保留名称搜索、9 色系筛选、最近使用、已有花枝、委托心愿角标；卡片新增「可翻瓣」小标签。
- 新增 4 步新手引导（挑一朵→添陪衬→试叶材→自由调整），可跳过、帮助入口可重看；修剪时自动让开画面。
- 花材架悬停/点「了解」打开右侧磨砂知识浮窗：认识它 / 怎么搭 / 照顾它，300ms 预览、满 2 秒固定，点外部/Esc/拖取关闭；32 花型内容，来源为维基条目（31 条实测 200），图片标注「模型示意图」。
- 目录扩到 **32 花型 / 57 配色**，全部指向真实 Lux3D 模型（新增绣球、蝴蝶兰两件真实模型，共 40 积分）。

**整理**
- 统一「整理」入口，按选中对象显示适用操作：玫瑰族翻瓣（三档手动 + 一键翻开 + 恢复原样，几何外翻约 +17%）、玫瑰族去刺、玫瑰/郁金香剪短与逐叶剪除、其它花材如实说明不显示假按钮；一键整束整理（一次撤销 + 恢复整理前，不含翻瓣）。
- 5 种宽口/内腔容器支持花泥：放入→按容器口裁切→适配枝脚→取出，换花瓶/纸包自动归零。
- 修复整理后「花瓣上冒出叶子 / 单枝叶子与刺浮空」：叶片按实际花头底部重排并加叶鞘包茎、刺改为细小低饱和绿褐短刺且刺根埋入茎；丝带高度改为按纸腰几何贴合。
- 整理面板去掉多余浮框，与「快捷微调」连成一张面板；整理文案改为面向玩家的说明。

**包装与装饰**
- 包装能力表统一 8 种呈现形态：只有纸片包装有可编辑丝带；花礼盒自带固定缎带不再因换色重建、不叠加第二个蝴蝶结；换容器自动过滤不支持的装饰（撤销可找回）。
- 「丝带」步骤扩为「装饰」：9 款辅助装饰（细灯串/星星灯/珍珠串/装饰细线/蝴蝶/星形/爱心插饰/蝴蝶结/吊牌），四组缩略图选择后调位置/旋转/大小/亮度/颜色，随作品保存、撤销、导出照片；纸包才有的灯串沿轮廓绕行。
- 委托 c6「纪念日礼盒」原来要求礼盒无法编辑的玫瑰色丝带，改为礼盒实际支持的「吊牌」，心愿标签同步。

**声音**
- 全流程动作音效（取放花、翻瓣、去刺、修叶、剪枝、花泥、折纸、系结、装饰、拍照、保存），WebAudio 现场合成，音量/静音偏好本机保存。
- 新增**背景音乐**：ModelScope ACE-Step 真实生成的 2 段循环氛围音乐（40.1s / 44.3s），顶栏音效面板可单独开关；BGM 音量低于动作音、切后台暂停、刷新保留偏好。

**贺卡**
- 贺卡新增常用短语（生日/感谢/纪念日/日常，各 3 条；正文非空时先问替换/追加）与 AI 润色（只发文字给服务端魔搭模型，建议先展示、采用才替换、可取消、迟到结果不覆盖、失败保留原文）。
- 贺卡编辑区重做视觉：分段开关、场合小签、纸签短语、字号间距统一。

**开屏与面板**
- 开屏「花间作品展」改为右侧无边框画册式展示，鼠标在右侧滚轮切换作品（01/06、圆点、箭头、方向键；窄屏按钮兜底）；工作台右栏的原作品展列表不受影响。
- 左右侧面板可拖拽拉伸（内边缘把手、键盘 ←/→ 调整、宽度本机保存，≤760px 回退原布局）；就近微调工具条会跟着右栏宽度让位。

## 未完成与已知边界

- 翻瓣是整模外壳形变（非逐瓣骨骼），满翻时略超未翻瓣的接触包络（约 1.5cm），接缝贴图轻微拉伸；只对玫瑰族开放。
- 非玫瑰/郁金香花材不支持剪短/逐叶修剪（现有真实模型没有分离茎尾与叶片），界面按能力隐藏而非假按钮。
- 花泥只对 5 种宽口/内腔容器开放；透明花瓶不塞花泥。
- 装饰参数是按钮步进，不是自由拖拽/绳索物理；灯无闪烁动画。
- 背景音乐未做人工听感验收；循环为 3s 交叉淡化近似；无 BGM 独立音量滑杆；自动播放被拒时静默降级。
- 叶片是朴素程序化单片叶（真实叶片方案已被用户否决回滚），近看叶缘平滑、无锯齿细节。
- 绣球花头 0.37–0.44m 是最大主花头，1024 贴图 2× 近看略软；蝴蝶兰一次模型只含 3 朵开放花 + 1–2 花苞。
- AI 润色真实上游只做少量联调，输出质量与拒答/限流边界仍需更多样本。
- 4K、移动端真机、弱网、触屏手势未做完整验收；391px 只验证布局不溢出。
