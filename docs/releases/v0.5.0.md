日期：2026-11-06。合并此前尚未推送的第五轮原型与本次反馈，统一作为第五次版本推送。

## 可以体验的变化

- 委托一次只显示一封来信，按钮、左右键和横向划动翻页；工作台以圆环表示完成进度，一次显示一条心愿，完整来信按需展开。
- Ctrl/Command + 滚轮缩放选中花枝，Shift 精细缩放；Ctrl/Command + D 复制，Delete 删除，1–4 切视角，F 对准选中，Home 复位，Ctrl/Command + Z 撤销。输入框和委托/相册弹窗不会误触花枝快捷键。
- 玫瑰和郁金香的长茎与叶片可手动修剪；成品新增可关闭的下部自动整理，返回编辑恢复原几何，保护花头构图。
- 花材扩到 5 花型、12 配色：在既有 3 个 GLB 家族上增加程序化多头玫瑰和非洲菊。多头作为一枝编辑、三个花头分别参与避让建议，无新增 Lux3D 任务。
- 1–3 张参数化独立纸片、花瓶/陶罐、换装预览与取消、姿态分开恢复；三节点工作流、按用途筛花、模型缩略图、三位固定人物。
- 窗边加深墙面与木色，新增墨绿展台，连同素台共三处摄影场景；统一预览、导出与相册构图。
- 每作品多张照片，各自保留制作版本和相机方向；支持封面、重开、复制和 PNG 导出，旧存档兼容，容量失败保护。
- 点击 AI 点评后，魔搭 Qwen/Qwen3.5-35B-A3B 观察照片，deepseek-ai/DeepSeek-V4.1-Flash-1017 根据观察与花材资料给主观评分、优点和建议。任务达成仍由明确规则判定。

## 边界

- 自动整理按保守下部包络过滤三角形，不是网格布尔运算；花头间/上部枝叶穿插、极端纸片折叠仍可能存在。只在成品或拍照启用，不改存档中的花枝位置。
- 多头玫瑰和非洲菊是程序化小样，与真实 GLB 的质感尚不完全一致。纸片还不支持自由揉纸或任意顶点拖动。
- AI 分数不是客观美学标准，视觉描述可能不准确。点评只保留在当前画面，不随相册保存；作品变化后旧点评失效。
- AI 需服务端 MODELSCOPE_API_KEY；纯静态托管无法独立调用。服务设超时、输入限制、缓存、串行与每日 60 次内存限额（重启重置），失败不会伪造评分或阻止存相册。
- localStorage 容量受浏览器限制；暂无跨设备相册、登录或数据库。
