# V7 / 0.7.0 · 花间一刻

日期：2026-11-06。用户先给 V0.7 计划并授权“直接开始做”“所有任务做完再说”，随后在验收录屏后指出「花抽搐了」。本次推送包含 §3–§8 全部已实施项，以及 V0.7.1 的接触形变抖动修复。V6 与 V7 分两次推送：V6 = tag `v0.6.0`，V7 = tag `v0.7.0`。

## 可以体验的变化

- **花头、枝长与包装比例**：新增逐种尺寸配置（`data/size.ts`）与 6 / 12 / 20 枝样束配方（`data/samples.ts`）；花头绕花头中心缩放并同步延长上半段茎，玫瑰、郁金香默认 80%；花头占用半径改为按缩放后实测，摆放建议、碰撞与包装随之同步。开箱即看：`?sample=12&head=0.8&view=quarter`。
- **三十种花材**：主花 / 配花 / 绿叶各 10 种，共 **30 花型 / 53 配色**。已有 5 种保持原样（玫瑰、郁金香、尤加利为真实 GLB；非洲菊、多头玫瑰为既有程序花），新增 25 种为**程序化几何**（单枝 316–3006 三角面），整枝等比标定并实测花头中心与半径。
- **轻量柔性接触**：花头相碰时按简化包络收拢（≤12%）、枝条偏转（≤5°）、正在拖动的一枝沿接触面让步（≤2.5cm）；形变是叠加层，不写作品文档、一次拖动只记一次撤销、拍照/成品阶段冻结同一状态。「挤进去是这一枝让，整束不漂走」。
- **接触抖动修复（V0.7.1）**：修复“拖动时花每约 100ms 弹回一帧”的抽搐，并把形变改成临界阻尼弹簧（挤入约 0.2s、恢复约 0.4s），多对接触取合力方向；12% / 5° / 2.5cm 上限不变。
- **点击 3D 对象直达编辑**：点贺卡进入卡片正文、点包装纸进入对应纸片、点花器进入花器选择，与包装进度分离；拍照阶段同样可用。
- **折叠视角控件**：右下角眼睛 + 视角名 + 下拉；固定模式下滚轮循环视角（累计阈值 90、320ms 节流），`Ctrl/⌘ + 滚轮` 优先调花枝大小，拖动空白自动退出固定模式；数字键 1–4 切视角。
- **评分服务入口**：`npm run dev:all` 一次启动前端与点评服务（端口占用中文提示、Ctrl+C 一起停）；新增不调模型的 `GET /api/health`（只报服务在线、凭据是否配置、`models: not_probed`）。

## 边界

- 25 种新增花材是程序化几何，形态与材质细节不如 Lux3D 精细模型；本轮没有创建任何 Lux3D 任务，也不把它们记成精细素材。
- 接触形变仍是「简化包络 + 参数化形变」，不是逐花瓣碰撞或软体模拟：**花瓣级、叶缘的局部穿插仍可能出现**；用户验收时也指出「会避开一点，但仍会穿模」——这一点列入下一轮改进（更大让步 / 位置分离求解 / 椭球包络），本轮不声称已消除穿模。
- 比例与包装观感（纸口遮花、层间穿插、正/侧/背面）仍需用户看截图与实机验收。
- 严格物理模拟只做了工程量与成本评估，未实施。
- 作品文档仍没有「比例/素材版本」字段，旧作品在 V7 发布后会按新比例与新素材渲染。
- 点评需要服务端 `MODELSCOPE_API_KEY`；纯静态托管无法独立调用。
