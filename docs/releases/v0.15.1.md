# V15.1 / 0.15.1 · 纸包前沿不再切进花材

日期：2026-11-10
类型：收尾后用户点名修复（非计划功能）

## 反馈与定位

用户看产品说明书里的包装截图后指出：「还是有点穿模，感觉是这个纸包装设计的原因，可以微调一下」，并选择「直接改并发布 v0.15.1」。

定位为参数化纸包的几何参数问题，不是 Lux3D 资产问题：

- `computeEnvelopeRadius()` 用花头水平位置加头径算外包络 `outer`，纸口半径取 `(outer + WRAP_RADIUS_MARGIN) × WRAP_RADIUS_TIGHTEN`，旧值 0.66 让纸口明显窄于花束外圈；
- 纸片几何的上沿高度固定为 `rows = [0, .12, .232, .34, .47]`，纸口正好落在配材（满天星、尤加利）下垂的位置；
- 两者叠加后，纸片前沿从花头/配材中间穿过，观感上像花从纸面里长出来。

## 修改

- `app/src/config.ts`：`WRAP_RADIUS_TIGHTEN` 0.66 → 0.72（纸口约宽 8%）。
- `app/src/three/decor/wrapping.ts`：纸口高度整体下压约 14%（`rows = [0, .104, .2, .292, .404]`），纸包前沿停在花材下缘。
- 版本 0.15.0 → 0.15.1（`app/package.json`、`app/package-lock.json`）。
- 未改花器、丝带、贺卡、GLB 资产与任何 Lux3D 任务；无新增积分消耗。

## 已知边界

- 纸包仍是单层开放式参数折叠，不是自由揉纸；花束特别分散时纸片仍可能与个别花枝轻微交叠。
- 纸口高度下压后，纸包整体比之前低约 14%，长颈花材露出的茎更长；视觉上更接近手绑花束。
- 未验收：移动端、4K、弱网；旧作品打开后按新参数重绘（存档只存参数，不存几何）。
