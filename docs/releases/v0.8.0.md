# V8 / 0.8.0 · 花材比例与自然接触

日期：2026-11-07。合并此前仅本地保存的 V0.7.2–V0.7.4 阶段改动，按一次正式推送计为 V8；历史阶段编号不代表独立发布。

## 体验变化

- 默认花材比例改为更紧凑的 b 档，花头、枝长与叶片协调缩小；已有作品保留原比例。
- 花头尺寸按实际可见顶点重新测量，接触包络随真实中心和朝向变化，修正斜向靠近时的“空气墙”。
- 玫瑰、郁金香在允许接触区内即产生轻量压缩，绕花头中心变形，释放平滑恢复；不会为正常接触把整枝推远。
- 拖动、新增、复制与精调共用落位约束，扫掠停止位置增加细化，减少离接触面提前停下的空隙。
- 延续 V6/V7 的 30 花型 / 53 配色、相册备份恢复、点评绑定照片、对象点击编辑和折叠视角控件。

## 保留的边界

接触是简化包络与局部形变，不是逐花瓣物理；程序化花材未全部拆出可独立压缩的花头，密集花束仍可能局部穿插。仅三类核心资产来自真实 Lux3D 生成，其余 27 种花型为程序化几何。纸包仍为参数折叠，移动端尚未完整适配。AI 依赖上游额度和网络；相册留在当前浏览器，重要作品应备份。
