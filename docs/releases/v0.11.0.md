# V11 / 0.11.0 · 再补三个拍照场景：节日暖光 / 家居客厅 / 咖啡馆

日期：2026-11-07。状态：本地实现与验证完成，随本轮推送并部署现有魔搭 Docker（部署与线上核验结果见文末）。

## 这一版变了什么

V10 把包装形态扩到 8 种、拍照场景扩到 5 个之后，用户说「可以，你继续做好了，自己验收，推送部署」。本轮按 [包装形态与场景扩展调研](../presentation-scene-expansion.md) 里排过优先级的候选，继续把**拍照场景从 5 个扩到 8 个**，全部是程序化 3D 布景（无新增付费生成、无外部贴图）：

| 新场景 | 布景构成 | 背景色 |
| --- | --- | --- |
| **节日暖光** | 酒红布幔背墙（低频布料褶皱 + 主体背后暖光晕）、深胡桃木台面、台沿桌旗、下垂串灯（灯线 + 14 颗自发光灯泡 + 加法光晕）、3 个礼物盒（酒红/奶油/金）、2 支蜡烛、木地板；组内 1 个暖色点光 | `#3b2a26` |
| **家居客厅** | 暖米白墙面、木色边柜台面、挂墙画框（程序化抽象色块）、布罩台灯（暖光）、沙发一角与抱枕、几本书与小陶罐、浅木地板 | `#e9dfd0` |
| **咖啡馆** | 浅橡木桌面、暖灰泥背墙、深胡桃木窗框与柔天光玻璃、深绿菜单板（横线示意、无文字）、咖啡杯碟勺、合上的杂志、陶盆小绿植、桌面窗光条 | `#ece4d8` |

三个布景都遵守同一套空间约定：原点即花束位置、台面顶面严格 0.66m、相机正面 0.6m 半径内保持通透、装饰集中在后侧与两侧；只在拍照/成品阶段显示，工作台阶段仍是素色台面。每个布景自带一套克制的补光（1 个点光或 1 个方向光），不压过场景主光。

配套：拍照场景入口从 5 个变 8 个（`PhotoControls` 自动按 `PHOTO_SCENES` 渲染）；相册记录、AI 点评上下文继续读同一份中文场景名；`photo.scene` 进入拍照签名，切换场景会让旧点评正确失效。

## 已知边界与未做

- 三个新场景是「拍照/成品阶段的一次性布景」：不可漫游，自由环绕到很侧面的角度仍可能看到台沿落差或墙边（沿用 V10 布景的边界）。
- 节日暖光的串灯是「自发光球 + 加法光晕面片」伪造的 bloom，没有后处理 Bloom；若以后加 Bloom 要同步压暗光晕避免过亮。场景补光不投影，礼物盒/蜡烛的落影来自场景主光，超出主光阴影锥时没有影子。
- 咖啡馆右侧物件在默认斜 45° 机位只露窄边，主要装饰在左侧与后方（与花店一角一致）。
- 新场景只在 1366×768 与 2048 导出路径下目检；4K、移动端窄屏、真实设备帧率仍未单独验收。
- 调研里剩下的候选：花环、玻璃钟罩、单支包装（需要新的摆花/单枝模式），以及婚礼签到台（工作量大），本轮未做。
