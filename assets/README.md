# 资产登记

真实模型放 `assets/local/`，登记清单按 `catalog.example.json` 结构另存为 `assets/local/catalog.json`。示例的资产列表为空，表示当前没有本项目生成成果。

每件资产至少记录：本地 ID、生成工具与模型版本、文本或参考图来源、任务号（无法获得就留空并说明）、生成时间、参数、耗时和积分消耗、GLB 路径、输入与输出哈希、可使用范围、视觉检查结论。不要保存含密钥的请求头或临时签名 URL。

坐标和视觉检查另记：原始单位与朝上轴、包围盒、导入旋转与缩放、材质是否正确、背面与薄结构是否可用。实际资产可在验证后按需要加入独立交付包；Git 忽略只是避免默认提交，不代表许可判断已完成。
